# Контрольная работа №3

**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».
**Проект:** Книжный магазин «Переплёт».

## Описание
Проект представляет собой адаптивную версию многостраничного сайта книжного магазина, выполненную на чистом HTML и CSS (с использованием JS для модального окна).
